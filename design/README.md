# Design — Gumbley AI rebrand

Brand assets and the UI design reference for the Gumbley AI rebrand of this fork.

- `Gumbley AI.dc.html` — target design reference (open in a browser); not code to copy
- `assets/` — logo, app icons (512/192/96), favicon
- `screenshots/` — reference captures
- `support.js` — prototype runtime only, not production code

Implementation notes and the full handoff documentation are maintained privately.
